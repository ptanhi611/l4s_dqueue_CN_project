# Final results

Generated by `eval/make_final.py` from the runs of `eval/run_final.sh`.
Raw data of every run (CSV/JSON, console output, config) is in the listed `experiments/` folders.

## Runs used

**Normal scenario:** `experiments/2026-11-21_0016_final_normal_r1`, `experiments/2026-11-21_0025_final_normal_r2`, `experiments/2026-11-21_0034_final_normal_r3`

**Attack scenario:** `experiments/2026-11-21_0020_final_attack_r1`, `experiments/2026-11-21_0029_final_attack_r2`, `experiments/2026-11-21_0038_final_attack_r3`

**Breaker off:** `experiments/2026-11-21_0043_final_breaker_off`

## Setup

- Mininet: h1 - r0 - h2, 50 Mbps bottleneck inside r0, 20 ms base RTT, 1.5 MB buffer (our router).
- Normal: 1 Classic flow (cubic, Not-ECT) + 1 L4S flow (DCTCP with ECN, ECT(1)) + 2 UDP latency probes (100 B every 10 ms; one ECT(1), one Not-ECT), 30 s.
- Attack: normal + 60 Mbps unresponsive ECT(1) UDP flood from t = 10 s to 30 s of a 40 s run. Attack numbers are measured from 2 s after the flood starts until it ends.
- Modes: FIFO, DualQ basic (no overload handling), DualQ (RFC 9332 incl. overload), DualQ+QP (our queue protection), DualQ+QP+limit (queue protection + 5 Mbps limit for sanctioned flows), Linux fq_codel, Linux sch_dualpi2.
